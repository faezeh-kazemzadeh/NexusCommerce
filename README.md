# 🚀 NexusCommerce

A high-performance **Full-stack MERN** E-commerce platform integrated with a powerful **Content Management System (CMS)**. This project is designed as a scalable solution for modern web commerce.

## ✨ Key Features
- 🛒 **Shopping Cart:** Seamless product selection and checkout flow.
- 📦 **CMS Module:** Dedicated system to manage products, categories, and content dynamically.
- 🔐 **Advanced Auth:** Secure User Authentication & Management system.
- 🐳 **Dockerized:** Fully containerized development and production environments.

## 🛠 Tech Stack
- **Frontend:** React.js (Vite)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **DevOps:** Docker, Docker Compose
